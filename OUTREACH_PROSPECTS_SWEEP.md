# Boba prospect sweep: 100 shops across 29 campuses

Built 2026-08-09 from OpenStreetMap (Overpass), the same source the app's map uses,
then every listed shop website scraped for a `mailto:`. Companion to
OUTREACH_PROSPECTS_EASTCOAST.md (which has the NY-registry owner names).

**Coverage gap:** Overpass kept timing out on three campuses, so Princeton,
Vassar/Marist Poughkeepsie and Penn/Drexel Philadelphia are NOT in this sweep.
Philly is only here via Boba King, found separately.

**Method note:** OSM only has what mappers entered, so absence here is not evidence
a shop lacks an email. It is a floor, not a census.

**Melchi's method for next time, and it is better than Overpass:** just web search
"boba shops in <town>". It returns a list in one query, never times out, and covers
shops no mapper ever tagged. Then chase each shop's own site or Instagram for the
contact. Use Overpass only when you want coordinates or a whole region at once.
