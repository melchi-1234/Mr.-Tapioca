How to get consistent results in Leonardo

Consistency is the whole game here — every asset has to look like it came from the same illustrator on the same day. Set these up once and keep them fixed:

1. Model / preset. Use Leonardo Phoenix for the cleanest take on this kawaii semi-flat vector look. If Phoenix drifts toward 3D/painterly, switch to the Illustrative or Anime preset (or Leonardo Diffusion XL with the *Illustrative* style). Keep the same model + preset for the entire pack — do not mix models between assets, or the line weight and shading will diverge.

2. Character Reference (most important for consistency). Upload assets/Mr. Tapioca.png as an Image Guidance → Character Reference (or *Style Reference* for non-character assets like cups, icons, and backgrounds). Keep strength around 0.4–0.6: high enough to lock the mascot's face, body sheen, palette, and outline style; low enough that the new pose/accessory still comes through. For UI icons and toppings, a lower strength (~0.3) as a *Style Reference* keeps the palette and outline consistent without forcing a pearl shape where it doesn't belong.

3. Transparency / background removal. For every cut-out asset (mascot frames, skins, cups, toppings, icons, badges, map pins, most mini-game sprites, glows, splashes) turn ON transparency / background removal so you get a clean PNG with alpha. The prompts say "FLAT PLAIN WHITE BACKGROUND" specifically because a flat white field removes cleanly — generate on white, then key it out. For full-bleed backgrounds (shop wallpapers, mini-game playfields) turn transparency OFF — those are scene art, not cut-outs.

4. Reuse the anchors every time. Paste the Style Anchor at the end of each prompt (already baked into every prompt below) and put the Negative Prompt in the negative field on every single generation. Same anchor + same negative + same character reference = a cohesive set.

5. Aspect & framing. Match the aspect ratio listed per asset. Keep the subject centered with comfortable margins so cut-outs don't clip. For animation frames, generate at the same aspect and scale so frames swap cleanly — ideally seed-lock or generate frames in one session.

6. Tip for animation frames: generate the neutral/idle frame first, then use *it* (not just the base PNG) as the character reference for the other frames in that loop. This keeps a walk/celebrate/idle loop internally consistent, not just consistent with the brand.
