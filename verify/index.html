Mr. Tapioca reward check

Staff only. Nothing to install.

Six characters. Spaces and dashes are fine.

What this check can and cannot tell you
  • It can tell you five things, and the server tests all five before it says VALID: the code came from the Mr. Tapioca server, it has not already been used, neither the code nor the reward behind it has run out of time, the shop's offer is still switched on, and the offer still reads the way it did when the reward was earned.
  • It cannot tell you that the reward belongs to this shop. The check reads the code and nothing else. It has no way to know which shop is holding this page, so a reward earned for another shop still reads VALID here. That is why the page asks you to confirm the shop name before it will let you mark anything used.
  • It cannot tell you anything about what the student actually did on their phone. Treat it as a valid coupon, not as proof of anything else.
  • Codes last about five minutes and stop working the moment one is marked used.
  • Staff tip: add ?shop= and your shop's name to the end of this page's link (for example ?shop=U Tea) and the page will check the name for you and refuse a reward from anywhere else. That is a setting on this device, not something the server enforces, so a typo in the link means good codes get refused.
